## Requirements

- Python 3.13+
- [uv](https://docs.astral.sh/uv/) (recommended)

## Install

```bash
git clone https://github.com/bdewitte/EvoSeerEngine.git
cd EvoSeerEngine
uv sync
```

## Verify

```bash
uv run pytest
```

All tests should pass.
