## Rationale

In Approximate Bayesian Computation (ABC), each candidate parameter set θ is evaluated by comparing a simulated distribution $F_n$ (based on n stochastic runs) to a reference distribution $R$. A sufficient number of runs per parameter set is needed to ensure that rejection of $\theta$ reflects a genuine mismatch between the model and the data — and not simply a poor Monte Carlo estimate of the underlying distribution.

Mathematically, we define $D(F_n, R)$ as a distance between the empirical distribution F_n (based on n Gillespie simulations) and the reference distribution $R$. We want to find the minimal $n$ such that the variance of $D$ is negligible — i.e. adding more simulations does not meaningfully change our estimate of the distance.

## Theoretical background

Estimating an unknown distribution $F$ from $n$ (independant and identically distributted) i.i.d. samples is a well-studied problem in nonparametric statistics. The answer depends critically on *what* we want to measure.

- **Estimating a scalar parameter** (e.g. the mean): the standard error decreases as $O(1/√n)$ by the Central Limit Theorem, so ~1500 samples are needed for ε = 0.05.
- **Estimating the full CDF uniformly**: the Dvoretzky-Kiefer-Wolfowitz (DKW) inequality gives a distribution-free bound: n ≥ ln(2/δ) / (2ε²). For ε = 0.05 and δ = 0.05, this yields n ≈ 738, regardless of the underlying distribution.
- **Estimating the density (PDF)**: much harder. The optimal MISE for kernel density estimators converges as $O(n^{−4/5})$ in dimension 1, degrading rapidly with dimension (curse of dimensionality).

In our case, we do not need to estimate the full density — we only need $D(F_n, R)$ to be a stable estimator of $D(F, R)$. By the functional CLT (Donsker's theorem), the empirical process $√n(F_n − F)$ converges to a Brownian bridge, which implies that any functional of $F_n$ (including our distance metrics) has a standard error decreasing as O(1/√n). The irreducible plateau visible in our empirical curves (see below) corresponds to the intrinsic stochastic variance of the Gillespie simulator itself — a lower bound that no amount of additional simulation can remove.

## Empirical estimation

To determine $n$ empirically, we fixed a reference parameter set and ran N = 500
Gillespie simulations. At each step $n$, we computed four distances between $F_n$ and $R$:
L1, L2, Kolmogorov-Smirnov (KS), and Wasserstein-1. The resulting curves were smoothed
and the first n where the relative variation fell below a threshold τ was recorded.

![Convergence of distance metrics as a function of n](/EvoSeer-Engine/research-notes/sample-by-simulation-convergence.png)

All four metrics show the same qualitative pattern: a rapid decrease up to n ≈ 20–50,
followed by damped oscillations and a clear plateau beyond n ≈ 100–150. KS converges
fastest (n = 26 for τ = 0.01), consistent with theory — it measures a bounded
functional of the CDF and is less sensitive to tail behaviour. L1 and Wasserstein
converge similarly (n ≈ 121), while L2 requires slightly more samples for strict
thresholds (n = 331 for τ = 0.0001).

For a threshold of τ = 0.01, **n ≈ 120–150 simulations** appears sufficient across
all metrics.

## The chicken-and-egg problem

The natural question is: can we determine n *before* running simulations? This requires
knowing σ²_sim, the variance of the simulator — but this variance itself depends on the
parameters θ being evaluated. In regions of parameter space near bifurcation points
(e.g. the OIS transition driven by BRAF V600E), the distribution of trajectories becomes
bimodal and variance can increase dramatically. A fixed n calibrated on one region may
be grossly insufficient in another.

This is a genuine chicken-and-egg problem: estimating n requires knowing σ²_sim, and
knowing σ²_sim requires running simulations.

## Solution: sequential stopping rule

Rather than fixing n in advance, we adopt a **sequential stopping rule** analogous to
early stopping in machine learning: simulations are added incrementally and stopped when
the estimated gain in D falls below a threshold.

Concretely, at each iteration we compute the smoothed derivative of D(F_n, R) with
respect to n. We stop when:

$$\left| \frac{\Delta D}{\Delta n} \right| < \tau$$

This mirrors the early stopping criterion used in neural network training, where
optimization is halted when the validation loss ceases to improve. The key theoretical
parallel is that both procedures track the **marginal gain of a noisy signal** that
decreases as O(1/√n), and stop at the empirical elbow of this curve. Unlike ML early
stopping — which also guards against overfitting and can see the loss *increase* —
our signal only oscillates around a stable plateau, making the stopping criterion more
robust and easier to calibrate.

This approach is formalized in the simulation literature as a **sequential stopping
rule** (Law & Kelton, *Simulation Modeling and Analysis*) and can be seen as a
**learning curve analysis** of the stochastic simulator: we ask not "does more data
help the model?" but "does more simulation help the estimator?"

## Practical recommendation

Based on the empirical analysis above, we recommend **n = 150 simulations per parameter
set** as a default for EvoSeer's ABC procedure under the current parameterization. This
value should be re-evaluated:

- In parameter regions suspected to be near the OIS bifurcation
- When the reference distribution R changes substantially (e.g. different patient data)
- If a stricter distance threshold is adopted in the ABC acceptance criterion

A lightweight pilot study (n = 50 runs on a coarse parameter grid) can be used to
map σ²_sim across the parameter space and identify regions requiring larger n.
